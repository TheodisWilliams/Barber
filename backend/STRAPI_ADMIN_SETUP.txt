=================================================================
🔒 SECURITY NOTES
=================================================================

✅ User Isolation:
   - API routes filter appointments by user email
   - Users can only see/modify their own appointments

✅ Protected Routes:
   - Dashboard requires authentication
   - Cancel endpoint verifies ownership

✅ Guest Bookings:
   - Guests can book without account
   - These bookings not visible in any user dashboard
   - Only shop owner sees them in Strapi admin
